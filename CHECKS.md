# Проверка решения

Проверка выполнена 14 октября 2026 года. Это перечень настоящих проверок, а не отчёт о завершённом развёртывании.

## Что прошло

- Все три файла Terraform разобраны HCL-парсером без ошибок.
- Все три YAML-файла Ansible разобраны без ошибок.
- Docker Compose принял конфигурацию через `docker compose config --quiet`.
- `bash -n scripts/monitor.sh` завершился без ошибок.
- Скрипт мониторинга проверен на тестовых логах и с подставными systemctl/journalctl. Подробности в `evidence/monitor-tests.txt`.
- Само-ревью подтвердило соответствие путей Ansible и Compose, разделение сетей, разные порты и подключение именованного тома.
- В коде нет комментариев; первая строка monitor.sh задаёт интерпретатор.

Разбор HCL не заменяет `terraform validate`, а проверка YAML не заменяет выполнение Ansible. Compose config проверяет конфигурацию без запуска контейнеров.

## Что осталось выполнить на Linux

1. Два запуска setup_host.yml и подтверждение changed=0 после второго.
2. Terraform init, validate, plan и apply.
3. Проверка 200 OK у Terraform-nginx и Hello World у Compose.
4. Проверка сетей и тома через docker inspect.
5. Мониторинг на настоящем локальном и удалённом Linux-хосте.
6. Настоящие скриншоты и публикация репозитория с PR/MR.
7. Тег v0.1.0 после мержа.

## Что помешало запуску здесь

Docker CLI установлен, но Docker Engine недоступен по named pipe. Запуск Docker Desktop не привёл к появлению доступного Engine. WSL отказал в перечислении дистрибутивов с E_ACCESSDENIED. Terraform CLI не установлен; попытки загрузить официальный архив завершились HTTP 404.

Ни один запуск terraform apply, второй Ansible changed=0 или HTTP 200 OK не заявлен выполненным без подтверждения.
